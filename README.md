# HSK Learning App

A Flutter mobile app for learning Mandarin Chinese based on the New HSK curriculum. Built with a local-first approach, the app helps learners start with HSK 1 through Pinyin, Hanzi, tones, randomized flashcards, quizzes, and offline progress tracking using local storage.
